# Worktree Cleanup Archive

This directory contains the temporary utilities and reports used for the 2026-08-12 legacy-worktree cleanup.

The scripts correlate registered Git worktrees with archived work-item evidence. The reports preserve the intermediate inventories, related-main assessments, mergeability review, and annotated cleanup decisions.

These artifacts are retained for historical reference. They are not active project tooling or current backlog authority.
