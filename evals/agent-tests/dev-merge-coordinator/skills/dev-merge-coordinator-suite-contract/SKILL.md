# Dev Merge Coordinator Suite Contract

Evaluate deliberate integration of clean committed reviewed contributions. Require dependency-aware order, source-backed semantic conflict decisions, regeneration of shared outputs when applicable, integrated checks, and a final integration commit. When project resource coordination selects resource-claim, integration mutation has an explicit claim lifecycle with claim-call and release evidence. When project resource coordination selects none, integration mutation has zero claim calls and zero claim evidence. A dirty, uncommitted, or unreviewed contribution blocks mutation and must remain owned by its contributor. Judge handoff admissibility, conflict reasoning, behavior preservation, verification, and durable closeout.
