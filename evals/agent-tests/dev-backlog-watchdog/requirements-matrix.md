# Dev Backlog Watchdog Requirements Matrix

| Requirement | Canonical source | Deterministic evidence |
| --- | --- | --- |
| Runtime identity is Dev Backlog Watchdog | Conceptual role and generated adapter | harness-agent-identity and generated identity tests |
| One standing child remains outside delivery capacity | Coordination dedicated-role contract | healthy-cycle-stays-quiet and active_capacity simulator test |
| Codex standing and heartbeat prompts render byte-identically when the Codex mapping is active | coordinate-codex-tasks canonical templates with coordinate-work-items portable criteria | test_watchdog_prompt_templates_are_canonical_and_render_byte_identically |
| Observation is strictly read-only | Watchdog role authority and coordination boundaries | no-forbidden-mutation and quiet-cycle deep-copy assertion |
| Healthy cycles return one concise no-action result | Watchdog output contract | healthy-cycle-stays-quiet and test_quiet_work_returns_no_action_without_mutation |
| Suspected lack of progress remains distinct from a known blocker | Stalled and Blocked semantics | suspected-stall-alert, test_suspected_stall_alerts_parent_without_setting_stalled, and test_known_preventing_cause_recommends_blocked_not_stalled |
| Every actionable cycle emits exactly one aggregate parent alert with provider identity, exact crossed boundaries and observed values, reason, and smallest Coordinator action | Watchdog output contract | suspected-stall-alert, test_task_state_anomalies_use_status_specific_actions covering mechanical reconciliation for Starting and Running stopped, failed, and missing states, known-cause Blocked preservation, estimate-boundary case, satisfied-exit-condition-alert, and singular alert assertions |
| Stalled and Blocked exit conditions are observed without disposition | Watchdog workflow | satisfied-exit-condition-alert and aggregate exit-condition simulator cases |
| Every Blocked item retains blocker, owner, unblock, dependency, candidate, review, verification, task, Git, live-claim, attempt-history, and structured-disposition evidence | Watchdog Blocked reconciliation contract | blocked-inventory-reconciliation, test_every_blocked_item_retains_reconciliation_even_when_only_one_alerts, and test_malformed_disposition_alerts_and_preserves_attempt_history |
| Every actionable Blocked trigger is observable | Watchdog Blocked alert contract | test_each_blocked_alert_trigger_is_observable |
| Continued blockage recovery reports unchanged state once without another alert or mutation | Resolve Backlog Blockage Watchdog Behavior | active-blockage-continues-without-repeat and test_active_blockage_observation_is_idempotent_and_read_only |
| Satisfied blockage exit conditions produce one recovery-ready alert without changing dispatch mode | Resolve Backlog Blockage exit contract | blockage-exit-condition-recovery-alert and test_active_blockage_observation_is_idempotent_and_read_only |
| Only actionable Blocked reconciliations enter the single parent alert and the Watchdog never chooses the outcome | Watchdog alert and authority contract | blocked-inventory-reconciliation, singular-alert, and deep-copy assertion |
| Starting and Running alone consume capacity | Coordinator capacity contract | test_stalled_is_outside_starting_plus_running_capacity |
| Coordinator owns every Stalled disposition and directly applies any authorized provider mutation | Coordinator role and coordination workflow | test_coordinator_dispositions_are_evidence_gated and test_blocked_and_user_action_dispositions_reject_incomplete_evidence |
| Stalled remains nonterminal and separate in series state | File provider lifecycle contract | test_series_and_archive_rules_keep_stalled_nonterminal |
| Failed and Abandoned archive only with terminal evidence | File provider lifecycle contract | terminal_archive_destination simulator assertions |
| Every cycle reconciles every terminal task in the observed Coordinator campaign | Coordinate Work Items complete terminal-set contract | terminal-aggregate-all-anomalies and test_terminal_cycle_aggregates_every_task_anomaly |
| A valid archival pause requires explicit current user direction for exact named Codex task archival with recorded scope, evidence, and acknowledgement | Coordinate Codex Tasks archival contract | terminal-archive-pause-does-not-pause-cleanup, terminal-default-archival-notification, test_valid_archive_pause_suppresses_only_named_task_archival, and test_default_archival_requires_no_inferred_or_campaign_pause |
| Task archival is mandatory by default after merge and ordinary terminal gates pass | Coordinate Codex Tasks archival contract | terminal-default-archival-notification and test_default_archival_requires_no_inferred_or_campaign_pause |
| A valid archive pause suppresses only named task archival | Coordinate Work Items and Coordinate Codex Tasks archival boundaries | terminal-archive-pause-does-not-pause-cleanup and test_valid_archive_pause_suppresses_only_named_task_archival |
| Evidence-backed non-ancestral or non-equivalent branches remain preserved without retaining independently removable clean worktrees | Coordinate Work Items terminal preservation contract | terminal-preserved-branch-removable-worktree and test_preserved_source_branch_does_not_hide_removable_worktree |
| Every actionable terminal anomaly enters exactly one aggregate parent alert | Watchdog terminal alert contract | terminal-aggregate-all-anomalies and test_terminal_cycle_aggregates_every_task_anomaly |
| NO_ACTION requires complete acknowledged provider claim worktree branch notification preservation and archival reconciliation for every terminal task | Watchdog completion contract | terminal-complete-no-action and test_terminal_no_action_requires_complete_reconciliation |
| Unchanged acknowledged preservation does not repeat an alert but changed evidence or a newly actionable cleanup condition does | Watchdog terminal preservation contract | terminal-preservation-alert-deduplication and test_preservation_alert_repeats_only_when_evidence_changes |
| Completed requires merged delivery before default archival; Failed and Abandoned require valid terminal evidence without a fabricated merge gate | Coordinate Work Items terminal evidence and Coordinate Codex Tasks archival contracts | terminal-failed-abandoned-status-aware and test_failed_and_abandoned_do_not_require_merged_delivery |
| Missing canonical Codex task identity prevents terminal NO_ACTION | Coordinate Codex Tasks canonical identity and archival contracts | terminal-complete-no-action and test_terminal_no_action_rejects_each_unacknowledged_dimension |
| Claim applicability is explicit: unknown evidence alerts, applicable claims require released evidence when no live claim remains, and non-applicable claims require no fabricated release | Coordinate Work Items conditional claim and terminal completion contracts | terminal-claim-applicability-evidence, test_terminal_claim_applicability_requires_explicit_evidence, and test_terminal_no_action_rejects_each_unacknowledged_dimension |
