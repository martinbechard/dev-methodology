# Dev Documentation Writer Suite Contract

Evaluate source-backed non-wiki documentation through exactly one applicable methodology or custom-page route. Require authoritative evidence, steady-state language, the route-specific artifact contract, explicit unresolved conflicts and gaps, truthful verification, and a clean commit and claim closeout. Preserve established README or custom-document format. Do not accept mixed templates, invented behavior, or a completeness claim for bounded or evidence-incomplete reverse engineering.

For a template-owned module design, require the target to load the canonical module design template before drafting and to preserve every level-two heading exactly once in template order. Require the first nonblank Implementation Readiness content to begin with READY. or BLOCKED. and to agree with the evidence-backed contract state. Run the fixture-native final validator before semantic judgment. Treat a heading mismatch, invalid readiness lead, unresolved template TODO, nonexistent source or test reference, unapproved verification command, or false automated-coverage claim as a critical deterministic failure. First-attempt conformance means the committed artifact passes these gates before reviewer or Judge correction; later repair does not satisfy the scenario.

Judge route correctness, source traceability, canonical structure, readiness integrity, test-evidence fidelity, artifact usefulness, verification integrity, and closeout.
