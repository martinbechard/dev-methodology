AI-Assisted Coding Toolkit

The toolkit provides portable Skills, conceptual Agent definitions, project guidance, and Evaluation methods for software development. The repository generator uses runtime adapter mappings to convert conceptual Agent definitions into supported Agent harness formats. Use this index to find each maintained explanation and its information owner.
