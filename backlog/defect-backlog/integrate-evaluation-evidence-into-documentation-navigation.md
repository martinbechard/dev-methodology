# Integrate Evaluation Evidence Into Documentation Navigation

Status: Ready

Type: Defect

Provider: file

Provider Reference: backlog/defect-backlog/integrate-evaluation-evidence-into-documentation-navigation.md

Completion: direct-main

## Summary

Make the Agent and Skill Evaluations document a standard member of the ordered HTML documentation set, with its own index tile and consistent previous and next navigation.

## Context

design/agent-and-skill-definitions.html currently exposes Evaluation Evidence as an unqualified button beside its standard next-page control. The linked design/agent-and-skill-evaluations.html page is not represented by a tile in the HTML Documents grid in index.html and is not part of the ordered document inventory used to generate and test previous and next navigation.

The evaluation page already links back to Core Agent and Skills, which establishes its logical position immediately after that document. The standard sequence should therefore flow from Core Agent and Skills to Evaluation Evidence to Agentic Configuration, with the remaining documentation order preserved. Because design/agent-and-skill-evaluations.html is generated by scripts/build-agent-skill-evaluation-docs.py, implementation must update the generator rather than hand-edit the generated page.

## Source Evidence

Direct user request in Codex task 019fae77-d530-7361-b1c6-36f87f3d6e28 on 2026-07-29: "in the agent-and-skill-definitions.html, there is a Evaluation Evidence button that doesn't follow the navigation standard. It should have a tile in the index and link up with previous and next buttons in the appropriate pages."

Repository evidence confirms that index.html omits design/agent-and-skill-evaluations.html from its HTML Documents tiles, design/agent-and-skill-definitions.html links to it without rel="next", and the generated evaluation page provides only a link back to Core Agent and Skills.

## Requirements

- Add one Evaluation Evidence tile to the HTML Documents grid in index.html.
- Place Evaluation Evidence immediately after Core Agent and Skills in the ordered documentation sequence.
- Use design/agent-and-skill-evaluations.html as the tile destination.
- Replace the ad hoc Evaluation Evidence button on design/agent-and-skill-definitions.html with the standard next-page control targeting Evaluation Evidence.
- Give design/agent-and-skill-evaluations.html standard previous and next controls: previous to Core Agent and Skills and next to Agentic Configuration.
- Update design/agentic-configuration.html so its standard previous control targets Evaluation Evidence.
- Preserve the existing relative order and links of all documentation pages that follow Agentic Configuration.
- Renumber index tile sequence indicators as needed so they remain contiguous and match the ordered document inventory.
- Update authoritative generator and test sources for the generated evaluation page instead of hand-editing generated output.
- Preserve the current evaluation page content, filters, source evidence, accessibility behavior, and generator freshness outside the navigation change.

## Acceptance Criteria

- The index displays exactly one Evaluation Evidence tile that links to design/agent-and-skill-evaluations.html.
- The index order begins Core Agent and Skills, Evaluation Evidence, Agentic Configuration.
- Core Agent and Skills has a standard next control to Evaluation Evidence and no separate ad hoc Evaluation Evidence button.
- Evaluation Evidence has a standard previous control to Core Agent and Skills and a standard next control to Agentic Configuration.
- Agentic Configuration has a standard previous control to Evaluation Evidence.
- Every documentation page remains reachable through the complete previous and next sequence without skipping or duplicating Evaluation Evidence.
- Index sequence indicators are contiguous and consistent with the navigation order.
- The evaluation-document generator reproduces the navigation change without freshness drift.
- No evaluation data, evidence qualification, filters, or page-specific section navigation changes as part of this defect.
