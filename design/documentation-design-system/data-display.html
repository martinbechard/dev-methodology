Concern 04

Data Display

Data-display components make repeated values, comparisons, states, and source mappings easy to scan. The suite uses tables for exact comparison and cards or metrics for compact summaries.

TopTablesMetricsStatusesCatalogsDefinitions

Tables And Horizontal Overflow

A table is appropriate when each row uses the same fields. Wide tables need a dedicated overflow wrapper instead of turning the table itself into a block.

Badges, Tags, And Statuses

Compact labels classify content or show state. They are not navigation controls. The text must carry the meaning because color alone is insufficient.

PassFailBlockedUser action requiredMethodologyNeutral

The source has three naming systems: .status--*, .badge*, and .tag. Some labels describe verdicts, some describe work-item states, and some describe taxonomy. Pill-shaped links belong to Suite Navigation, even when they look similar to badges.
