Test-Only Interaction Sources

Four tracked HTML fixtures supply controls and accessibility states that are not part of the production documentation shell.

  • settings.html supplies a persisted checkbox and role="status".
  • upload.html supplies a file input, button, and role="alert".
  • complete-flow.html supplies required email validation, hidden steps, focus movement, live progress, and recovery.
  • accessibility-defects.html is a deliberate negative example with an unlabeled text input and weak progress text. Do not copy it as a component.
