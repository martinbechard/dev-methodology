Content

Content components organize explanation from page-level concepts down to exact identifiers. The source suite combines semantic HTML with reusable card, callout, note, panel, and code treatments.

Text Hierarchy

Headings identify page, section, subsection, and boundary levels. A lede carries the opening definition, and body paragraphs carry one related idea at a time.

Context label

Section heading

Subsection heading

Boundary heading

A lede gives the reader the central idea before details.

Body prose can use strong importance, a visual label, an inline link, and an exact configuration.identifier.

Small text supports captions, paths, and secondary metadata.

Lists And Definitions

Ordered lists represent sequences. Unordered lists represent sets. Description lists pair stable terms with their definitions.

Unordered

  • Verification evidence
  • Known limitation

Ordered

  1. Select the source.
  2. Run the exact check.
  3. Record the result.

Callouts, Notes, And Asides

Callouts emphasize an important boundary. Notes provide secondary context. Asides hold related information that is not part of the main narrative flow.

Evidence boundary

A declaration is not a verified result.

Decision pending

The variation audit records options but does not select one.

This supporting detail remains useful without becoming the main claim.
